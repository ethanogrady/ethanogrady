# ethanogrady.com

Next.js static export, deployed to Cloudflare Pages. All content lives in Sanity.

## Updating the site

Everything the site shows is edited in Sanity Studio. Nothing needs code changes.

| What | Where |
| --- | --- |
| Add, edit, reorder projects | Studio → Projects |
| Reorder projects on the grid | Drag rows in the Projects list |
| Reorder images inside a project | Drag thumbnails in the Images field |
| Upload many images at once | Open a project → Images → "Upload multiple images" |
| Info page text, portrait, contact, socials | Studio → Info |
| Name in the header | Studio → Info → Name in the header |
| Browse and reuse uploaded images | Studio → Media |

Ordering is drag-and-drop everywhere. There are no order numbers to maintain.

### Publishing changes

The site is statically built, so edits appear after a rebuild. Publishing in
Sanity triggers a Cloudflare rebuild once the webhook below is connected.

## One-time setup still required

1. **Deploy the Studio** so the client has a URL:

   ```bash
   npx sanity login
   npm run studio:deploy
   ```

   This publishes to `https://ethanogrady.sanity.studio`.

2. **Invite the client** at
   `https://www.sanity.io/manage/project/pfn0vjso/members` as an Editor.

3. **Connect publish to deploy.** Create a Cloudflare Pages deploy hook
   (Pages project → Settings → Builds & deployments → Deploy hooks), then add
   it in Sanity as a webhook
   (`https://www.sanity.io/manage/project/pfn0vjso/api/webhooks`) firing on
   create, update, and delete for the `project` and `siteSettings` types.

   Without this, edits will not appear until the next push or manual deploy.

## Local development

```bash
npm run dev            # site on :3000
npm run studio         # Sanity Studio on :3333
npm run build          # static export to out/
npm run verify         # reproduce the CI install check
```

`.env.local` holds the Sanity project id, dataset, and a write token. It is
gitignored. The project id and dataset are also hardcoded as fallbacks in
`sanity/env.ts`, so Cloudflare builds work without any environment variables.

## Deployment

Cloudflare Pages, build command `npm run build`, output directory `out`.
Set `NODE_VERSION` to `22`. Node is pinned in `.nvmrc` because the lockfile
must be generated by the same npm major the builder runs, or `npm ci` fails.

## Images

Images are stored in Sanity and served from its CDN, resized on demand by
`lib/imageLoader.ts`. The build output is around 2.6 MB because no images ship
with it.

Source images were migrated from the previous build's 2048px WebP exports, as
the camera originals were deleted before the migration. 2048px is therefore the
maximum available width for existing projects. Newly uploaded images are not
affected and can be any size.
